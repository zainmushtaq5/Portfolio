# Zain Mushtaq - Portfolio

A modern, high-performance portfolio website built with Next.js 15 (App Router), React 19, Tailwind CSS, Prisma, and Gemini AI. 

## 🚀 Features

- **Custom AI Chatbot:** Talk to a RAG-powered assistant that knows about my experience and projects.
- **Dynamic Projects Showcase:** Case studies driven by a custom data store.
- **GSAP Animations:** Smooth timeline-based animations for achievements.
- **Modern UI:** Glassmorphism, noise textures, and custom cursors via Framer Motion.
- **Admin Dashboard:** Secure backend to view chat logs, leads, and contact messages.

## 🛠 Tech Stack

- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS + Shadcn UI
- **Animations:** Framer Motion + GSAP
- **Database:** PostgreSQL (Neon) via Prisma ORM
- **AI Integration:** Google Gemini API (`@google/genai`)

## 🏃‍♂️ Getting Started

1. Clone the repository.
2. Install dependencies: `npm install`
3. Setup `.env.local` (Copy from `.env.local.example`)
4. Generate Prisma Client: `npx prisma generate`
5. Push schema: `npx prisma db push`
6. Run dev server: `npm run dev`
