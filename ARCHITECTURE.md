# Architecture

## Overview
This Next.js 15 application leverages Server Components and the App Router to deliver a fast, SEO-optimized portfolio experience.

## Database (Prisma + Neon)
- **RateLimitRequest:** Distributed tracking for the AI chatbot and login attempts.
- **ChatSession & Message:** Stores conversation history for context tracking.
- **ContactMessage:** Stores messages sent from the contact form.
- **Lead:** Captures potential client emails dynamically generated by the AI chatbot.

## AI Chatbot (Gemini)
The chatbot leverages the `@google/genai` SDK using a streaming architecture (`NextResponse`). Context is injected via a static RAG pipeline combining `personal.ts`, `projects.ts`, and `numbers.ts`. It securely writes history out-of-band using Next.js 15 `after()`.

## Admin Panel
A lightweight, secure Server Action based dashboard built into `/admin`. Authentication is achieved via HMAC SHA-256 signed tokens using an environment secret, ensuring zero external dependencies for auth.
